# Code of Conduct

Cairn is a small community project. Participants are expected to be respectful, constructive, and considerate of different experiences and backgrounds.

Unacceptable behavior includes harassment, personal attacks, discrimination, publishing private information, and deliberate disruption. Maintainers may remove comments, close contributions, or restrict participation when needed to keep the project welcoming.

Report concerns privately through the security contact described in [SECURITY.md](./SECURITY.md).

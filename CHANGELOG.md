# Changelog

All notable changes to Cairn are documented here.

## 1.0.0

- Initial release of Cairn.
- Scan vault Markdown files for a configurable marker keyword (default `TODO`).
- Sidebar with tag-grouped markers, inline wiki-link navigation, and drag-to-tag.
- Editor and reading-view highlighting for the marker keyword.
- File Explorer indicators for files containing markers.
